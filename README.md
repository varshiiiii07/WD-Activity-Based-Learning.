## Project Overview

This repository contains website design activities created using **HTML
and CSS** as part of the Web Development Activity-Based Learning
project.

## Websites Included

1.  **Sweet Bakery** --- Displays cakes, pastries, cookies, seasonal
    offers, custom cake information, and contact details.
2.  **Foodie Restaurant** --- Displays food menu items, prices, order
    buttons, special offers, customer reviews, and contact details.
3.  **Digital Library** --- Displays books, authors, availability
    information, and search/category controls.

## Technologies Used

-   HTML5
-   CSS3

## How to Run

1.  Download or clone this repository.
2.  Open the project folder on your computer.
3.  Open the required `.html` file in a web browser.
4.  If a separate CSS file is used, keep it in the same folder as its
    corresponding HTML file.

## Project Purpose

The purpose of this project is to practise creating simple, structured,
and user-friendly web pages using HTML and CSS.
